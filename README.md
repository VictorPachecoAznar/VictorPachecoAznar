## 🛰️ Featured work

### Open-Vocabulary 3D Segmentation of Radiance Meshes
*MSc semester project, ETH Zürich (Photogrammetry & Remote Sensing Lab)*

Distilling a frozen 2D vision-language teacher (CLIP, via AMRADIO) into a 3D tetrahedral
radiance mesh, then asking whether the distilled features stay consistent across views and
form meaningful 3D regions. The 3D student ends up **more view-consistent than the 2D teacher
it learned from** — distillation into the tetrahedral structure acts as a geometry-aware prior.

Pipeline: CLIP/AMRADIO teacher → Instant-NGP backbone → explicit radiance-mesh refinement.
Evaluated on the NeRF *Garden* scene over 116k matched keypoints and ~13M tetrahedra.

→ **[Project page & full findings](https://victorpachecoaznar.github.io/RadianceM_3DSemSeg/)**

### apb_spatial_computer_vision
*Bachelor's thesis · Port de Barcelona × UPC · graded 10/10 with honours*

A Python library that brings computer vision to large-scale geospatial imagery. Open-vocabulary
segmentation driven by **Grounding DINO** (text → bounding box) and **SAM** (box → mask), with
spatial-SQL post-processing in **DuckDB** and concurrency-optimised **GDAL** image pyramids.
Packaged for reproducibility (Conda environments, PyPI release, CI/CD, MkDocs documentation).
Awarded *best individual AI project* at UPC-EPSEB.

→ **[Repository](https://github.com/VictorPachecoAznar/TFG)** · **[Documentation](https://victorpachecoaznar.github.io/TFG/)**
